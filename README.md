# SudokuFunny

Sudoku 9×9 ως δωρεάν PWA για κινητό και υπολογιστή. Επίπεδα δυσκολίας, αυτόματη αποθήκευση, ασφαλής παύση όταν η εφαρμογή δεν είναι ενεργή, σημειώσεις και χρονόμετρο.

Δεδομένα μόνο τοπικά στη συσκευή (localStorage). Δεν απαιτείται λογαριασμός ή βάση δεδομένων.

Η παρτίδα διατηρείται κατά την αλλαγή εφαρμογής ή το κλείσιμο της συσκευής. Για αποφυγή απώλειας, **μην κάνετε εκκαθάριση δεδομένων ιστότοπου**.
