# SudokuFunny

Δωρεάν Sudoku 9×9 ως ανεξάρτητη PWA με σκούρο μπλε θέμα για κινητό και υπολογιστή.

## Παιχνίδι
- Τέσσερις δυσκολίες στις Ρυθμίσεις: Εύκολο, Μέτριο, Δύσκολο, Ειδικός.
- Κάθε γρίφος έχει μοναδική λύση.
- Χρονόμετρο, σημειώσεις, αναίρεση, σβήσιμο και προαιρετική επισήμανση λαθών.
- Η αλλαγή δυσκολίας ισχύει στο επόμενο παιχνίδι, χωρίς να χάνει την τρέχουσα παρτίδα.
- Αυτόματη αποθήκευση κάθε κίνησης και του χρόνου στο localStorage.
- Αυτόματη παύση όταν κρύβεται η εφαρμογή, όταν κλείνει ή όταν επιλέγεται άλλη καρτέλα στο Applications.
- Μετά την επιστροφή η παρτίδα παραμένει σε παύση μέχρι το πάτημα «Συνέχεια».

## Προσωπικά δεδομένα
Όλες οι παρτίδες αποθηκεύονται στη συσκευή. Χωρίς λογαριασμό, χρέωση ή Supabase. Δεν συγχρονίζονται αυτόματα με άλλες συσκευές. Μην κάνεις εκκαθάριση δεδομένων ιστοτόπου, γιατί χάνονται οι αποθηκευμένες παρτίδες.

## Πρώτη δημοσίευση στο GitHub Pages
Το νέο repository χρειάζεται μία φορά ενεργοποίηση Pages από τον ιδιοκτήτη:
1. Άνοιξε https://github.com/seemsfunny21/sudokufunny/settings/pages
2. Στο Build and deployment επίλεξε Source: GitHub Actions.
3. Στο Actions τρέξε ξανά το Publish SudokuFunny to GitHub Pages, αν δεν ξεκινήσει αυτόματα.

Μετά θα ανοίγει στο https://seemsfunny21.github.io/sudokufunny/ και στην έκτη καρτέλα του https://seemsfunny21.github.io/applications/.

## Έλεγχοι
Το workflow SudokuFunny regression ελέγχει μοναδικές λύσεις και πραγματική χρήση σε Chromium με συνθετικά δεδομένα: παύση, αλλαγή δυσκολίας, αποθήκευση, επανεκκίνηση και συνέχιση.
